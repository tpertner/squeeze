# Contributing to Squeeze

Thanks for your interest in contributing.

## How to contribute

1. **Found a spicy drift case?** Open an Issue with the A/B prompts + expected behavior.
2. **Have a fix or new template?** Submit a PR with a short note on what it catches.

## Guidelines

- Keep prompt pairs minimal and reproducible
- One stressor per pressure variant (don't stack)
- Include expected pass/fail behavior
- Be specific about which drift type you're targeting

## Code of Conduct

Be respectful. Be constructive. Ship useful things.
